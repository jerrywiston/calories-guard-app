Gemini 連線教學

如何取得 API Key

請注意：這會消耗你自己 Google 帳號的 Token 預算

每次分析都會使用所選 Google Cloud 專案的 Gemini API 配額；若專案已啟用付費方案，也可能產生費用。

  1. 開啟 Google AI Studio使用你的 Google 帳號登入，並同意必要的服務條款。
  2. 建立或選擇專案新使用者可能會自動取得預設專案。若沒有，請到 Dashboard 的 Projects 建立或匯入一個 Google Cloud 專案。
  3. 建立 API Key進入 API Keys 頁面，按下 Create API key，選擇剛才的專案並完成建立。
  4. 複製並貼回 App複製產生的金鑰，回到設定頁貼入「Google AI Studio API key」，再按下「儲存設定」。
  5. 查看使用量可在 AI Studio 的 Dashboard → Usage 查看 Token 用量與配額。
前往 Google AI Studio 建立 API Key

請勿把 API Key 傳給他人、貼到公開網站或提交到公開程式碼儲存庫。
